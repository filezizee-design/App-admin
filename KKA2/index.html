Pengaturan Integrasi Google Sheet Guru

Sesi Guru Terverifikasi

Setiap siswa mengklik tombol "Kirim Nilai ke Sheet Guru", nama, kelas (TSM I / TSM R), skor, kode Python, dan output terminal akan otomatis dicatat sebagai baris baru di Google Spreadsheet Anda.

Langkah Memasang Google Sheet Guru (3 Menit):

  1. Buka sheets.new di browser untuk membuat spreadsheet baru. Beri judul misal: "Rekap Nilai Koding TSM SMKN 1 Pleret".
  2. Klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua teks bawaan, lalu klik tombol di bawah untuk menyalin kode Apps Script:
  4. Klik tombol biru Terapkan (Deploy) di kanan atas → pilih Penerapan baru (New deployment).
  5. Pilih jenis: Aplikasi Web (Web App).
  6. Bagian "Siapa yang memiliki akses (Who has access)": pilih "Siapa saja (Anyone)" (PENTING!).
  7. Klik Terapkan, beri otorisasi akun Google Anda, lalu salin URL Aplikasi Web yang berakhiran /exec.
  8. Tempelkan URL tersebut ke kolom di bawah ini.
Anda juga bisa menempelkannya permanen di file js/config.js untuk seluruh komputer lab.
